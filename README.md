# 갈림길과 되풀이

95점인데 B 학점? — 오류 없이 결과만 틀리는 조건 순서의 함정을 한 줄씩 실행하며 풀어 보는 파이썬 조건문·반복문 체험 앱입니다. 순서도, if/elif/else, 따로 쓴 if, 비교 기호와 경계값, and·or·not 전구 회로와 계산 순서, 중첩 조건(로그인), for와 break·continue, while 무한 반복 막기, 리스트 내포, 온도 알람과 겹친 반복의 break까지 담았습니다. 파이썬 03 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 갈림길: 재고 순서도, 잘못된 순서 vs 고친 순서 학점 코드 한 줄씩 실행, 퀴즈 ①(if 두 번)
- ② 조건 묶기: 비교 기호와 경계값, and·or·not 전구 회로, 논리 연산 계산 순서, 로그인 중첩 조건
- ③ 되풀이: 온도 리스트 for 실행기(continue·break), 퀴즈 ②, while 재시도와 횟수 제한, 리스트 내포
- ④ 온도 알람: 위험·주의·정상 분류와 조건 순서 함정, 겹친 반복의 break 예측·실행, 세 줄 정리
